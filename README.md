# Rooted In Christ Ministry

Phase 1 foundation for a ministry and humanitarian platform built with Next.js and TypeScript.

## Local development

```bash
pnpm install
pnpm dev
```

## Content safeguards

- No pricing or commercial package information belongs in this project.
- Do not invent ministry leaders, registration details, contact information, statistics, outcomes, or financial information.
- Beneficiary and assistance information must remain private by default.
- Operational forms must not ship until server-side validation, persistence, authorization, and abuse controls are implemented.
- Basic private donation records are in scope; accounting, expenses, financial reporting, and active payment processing are not. Optional gateway fields are reserved for a future approved integration.

## Current scope

Phase 1 includes the public design system, responsive navigation, homepage, public route placeholders, metadata, accessibility foundations, and baseline security headers. Database, authentication, admin tools, and operational forms are intentionally reserved for later verified phases.
